## 🌟 ૧. પ્રોજેક્ટ વિશેષતાઓ (Key Features)

### 🖥️ પબ્લિક ન્યૂઝ પોર્ટલ (Public Website)
- **આધુનિક રિસ્પોન્સિવ ડિઝાઇન:** મોબાઇલ, ટેબ્લેટ અને ડેસ્કટોપ માટે શ્રેષ્ઠ વાંચન અનુભવ.
- **બ્રેકિંગ ન્યૂઝ ટિકર (Breaking News Ticker):** લાલ બેજ સાથે જીવંત સ્ક્રોલિંગ હેડલાઇન્સ.
- **મુખ્ય સમાચાર (Hero Section):** મોટો વિઝ્યુઅલ ફોટો, શ્રેણી અને ગુજરાતી હેડલાઇન.
- **ટ્રેન્ડિંગ ન્યૂઝ (Trending News 1-10):** એડમિન નિયંત્રિત ક્રમ મુજબ ટ્રેન્ડિંગ યાદી.
- **૧૦+ ગુજરાતી કેટેગરીઝ:** ગુજરાત, ભારત, વિશ્વ, રાજકારણ, વેપાર, ટેકનોલોજી, રમતગમત, મનોરંજન, આરોગ્ય, શિક્ષણ.
- **સમાચાર વાંચન પેજ (News Detail Page):** સંપૂર્ણ લેખ, બ્રેડક્રમ્બ્સ, સોશિયલ મીડિયા શેરિંગ (WhatsApp, Facebook, Twitter), સંબંધિત સમાચાર અને સ્ત્રોત એટ્રિબ્યુશન.
- **લાઈવ ટીવી (Live TV):** ૨૪ કલાક અવિરત સમાચાર સ્ટ્રીમ.
- **ઝડપી શોધ (Search):** કીવર્ડ દ્વારા તમામ ગુજરાતી સમાચારોની ત્વરિત શોધ.

### ⚙️ સંપાદકીય એડમિન ડેશબોર્ડ (Admin CMS Panel)
- **URL:** `/admin`
- **લાઈવ ડેટાબેઝ KPIs:** કુલ સમાચાર, પ્રકાશિત, પેન્ડિંગ રિવ્યૂ, ડ્રાફ્ટ્સ, આજના સમાચાર, સક્રિય RSS સ્ત્રોતો.
- **૭ દિવસનું પ્રકાશન ચાર્ટ:** દૈનિક સમાચાર પ્રકાશન વલણ.
- **પેન્ડિંગ ન્યૂઝ રિવ્યૂ એડિટર (Side-by-Side Review):**
  - **ડાબી બાજુ (LEFT):** મૂળ RSS સ્ત્રોતની હેડલાઇન, વર્ણન, ફોટો અને ઓરિજિનલ લિંક.
  - **જમણી બાજુ (RIGHT):** BN News સંપાદિત ગુજરાતી હેડલાઇન, સારાંશ, સંપાદકીય સામગ્રી, કેટેગરી અને SEO મેટાડેટા.
  - **ક્રિયાઓ:** Save Draft, Approve & Publish, Reject.
- **કઠોર પ્રકાશન નિયમ (Strict Rule):** RSS દ્વારા આયાત થયેલ તમામ સમાચાર હંમેશા **PENDING** સ્થિતિમાં જ સાચવવામાં આવે છે. કોઈ પણ સમાચાર એડિટર/એડમિનની સમીક્ષા વિના સીધા પ્રકાશિત થતા નથી.
- **મેન્યુઅલ સમાચાર નિર્માણ:** સ્વતંત્ર રીતે સંપૂર્ણ ગુજરાતી આર્ટિકલ બનાવવું.
- **RSS સ્ત્રોત સંચાલન:** નવો સ્ત્રોત ઉમેરો, કનેક્શન ટેસ્ટ, અંતરાલ સેટ કરો (ડિફોલ્ટ 30 મિનિટ), અને **"ફેચ નાવ (Fetch Now)"** બટન.
- **મીડિયા લાઇબ્રેરી:** WebP ઓપ્ટિમાઇઝેશન સાથે સુરક્ષિત ફોટો અપલોડ અને થંબનેલ જનરેશન.
- **વપરાશકર્તા અધિકારો (RBAC):** SUPER ADMIN, ADMIN, EDITOR, REPORTER.
- **સુરક્ષા ઓડિટ લૉગ્સ (Audit Logs):** તમામ સંપાદકીય ક્રિયાઓનો અપરિવર્તનીય રેકોર્ડ.

## 🛠️ ૩. ટેકનોલોજી સ્ટેક (Tech Stack)

- **Frontend:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Lucide React, Axios
- **Backend:** Node.js, Express.js, TypeScript, Prisma ORM, Multer, Sharp (WebP), Helmet, CORS, Rate Limit
- **Database:** PostgreSQL (UUID Keys, Indexes, Foreign Keys, Audit Trail)
- **Background Automation:** BullMQ, Redis, RSS Parser
- **Deployment:** Ubuntu VPS, Nginx Reverse Proxy, PM2 Process Manager, Let's Encrypt SSL

## 🚀 ૫. લોકલ સેટઅપ અને રન કરવાની રીત (Local Setup Guide)

### ૧. બેકએન્ડ શરૂ કરો (Backend Setup)
```bash
cd backend

# પર્યાવરણ ફાઇલ રૂપરેખાંકિત કરો
cp .env.example .env

# ડેટાબેઝ સ્કીમા અને સીડ રન કરો
npx prisma generate
npx prisma db push
npm run prisma:seed

# ડેવલપમેન્ટ સર્વર શરૂ કરો
npm run dev
```
*બેકએન્ડ API `http://localhost:5000` પર સક્રિય થશે.*

### ૨. ફ્રન્ટએન્ડ શરૂ કરો (Frontend Setup)
```bash
cd frontend

# ડેવલપમેન્ટ સર્વર શરૂ કરો
npm run dev
```
*પબ્લિક પોર્ટલ `http://localhost:3000` પર ઉપલબ્ધ થશે.*  
*એડમિન પેનલ `http://localhost:3000/admin` પર ઉપલબ્ધ થશે.*

## 🌐 ૭. Ubuntu Hostinger VPS ડિપ્લોયમેન્ટ (VPS Deployment)

1. VPS પર કોડ ક્લોન કરો:
   ```bash
   git clone <repo-url> /var/www/bn-news
   cd /var/www/bn-news
   ```
2. એક જ આદેશમાં ડિપ્લોય કરો:
   ```bash
   chmod +x scripts/*.sh
   ./scripts/deploy.sh
   ```
3. ફ્રી SSL સક્રિય કરો:
   ```bash
   sudo certbot --nginx -d bnnews.in -d www.bnnews.in -d api.bnnews.in -d admin.bnnews.in
   ```
